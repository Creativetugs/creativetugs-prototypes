# Samantha Tilley Psychotherapy & Associates — Homepage Concept

A responsive HTML/CSS/JavaScript homepage concept based on the supplied website content and brand stylesheet.

## Preview
Open `index.html` in a browser, or upload the folder to GitHub Pages.

## Included
- `index.html` — semantic homepage structure and SEO metadata
- `styles.css` — responsive visual system, layout and motion
- `script.js` — mobile navigation, scroll header, sticky mobile booking CTA and reveal animations

## Brand direction
- Plum: #6E3B47
- Deep plum: #55293A
- Rose: #C4868E
- Soft pink: #F4DCDC
- Blush: #FBF2F2
- Headings: Cormorant Garamond
- Body: DM Sans

## Notes before launch
This is a design concept, not a production-ready clinical website. Confirm all service descriptions, credentials, availability, privacy language, accessibility, SEO metadata, image rights, and third-party links with Samantha before publishing. The homepage uses her existing headshot URL and links to her current Jane App, Stan Store and website resources. The burnout check-in and booking systems remain linked to their existing services; they are not recreated in this prototype.
