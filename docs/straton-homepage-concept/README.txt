STRATON INDUSTRIES — STATIC HOMEPAGE CONCEPT
================================================

Files
- index.html   Homepage markup
- styles.css   Responsive styles and visual system
- script.js    Mobile navigation, Manufacturing Path Finder, and demo RFQ summary

Preview locally
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.

Deploy
- Upload all three files to the same directory on your static host (for example, GitHub Pages).
- Keep index.html at the root of the published directory.

Important before production
- This is an outreach/mockup concept, not an official Straton Industries website.
- The RFQ form is a front-end demonstration. It does not send or store submissions. Connect it to an approved CRM or form endpoint before launch.
- The logo and some photographs are loaded from external URLs. For a production build, confirm usage rights and consider locally hosting optimized assets.
- Customer names/logos are text placeholders for concept presentation. Confirm permission and approved brand assets before publishing.
- Review all links, certifications, equipment/capability statements, and contact details with Straton before launch.
- Do not invite users to upload ITAR-controlled or otherwise sensitive technical files through an unapproved form.
