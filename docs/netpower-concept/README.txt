NET POWER WEBSITE CONCEPT

A homepage concept for a conversation with Net Power. It uses the company’s public logo, icons, photography, and facility film, and it adds the stakeholder tools described in the enquiry: plant capacity, production performance, technology specifications, grid interconnection, sustainability resources, and a project enquiry.

Files
- index.html: concept homepage
- styles.css: layout and visual styling
- script.js: navigation, film control, stakeholder tabs, enquiry preview
- assets/: logo, icons, photographs, and a compressed copy of the public facility film

How to preview
Open index.html in a modern browser. Google Fonts load from the internet. Everything else is local.

What a reviewer should click
- Pause film, in the hero
- Stakeholder view tabs: capacity, performance, technology, grid, sustainability
- Prepare enquiry, which previews the message on the page and does not send it

Content notes
- Unofficial Creative Tugs concept. Not affiliated with or endorsed by Net Power.
- ~200 MW is generation equipment contracted for Project Permian’s first phase. It is not stated as operating output.
- 1.X GW is the company’s stated design path, not contracted capacity.
- The performance chart is a sample shape. It is labeled as such.
- Grid voltage, queue position, and in-service timing are left for approved studies. They are not invented.
- The enquiry form does not transmit or store anything.
