Working concept

NannyConnect

Childcare, matched to the family.

A platform connecting families with qualified nannies, so they can discover childcare professionals, compare profiles, schedule care, and manage payments.

Name and branding are placeholders for the client.

  1. Join as a parent and open Elena Vargas.
  2. Request a booking and confirm the sample payment.
  3. Switch to the nanny dashboard and accept it.
  4. Return to My Bookings and see it confirmed.
