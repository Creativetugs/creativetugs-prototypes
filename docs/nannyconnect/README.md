# NannyConnect

Interactive mobile prototype for a nanny marketplace and childcare management app. Working name, for client review.

Families can browse nannies, compare profiles, and request a booking. The nanny dashboard accepts or declines that request. Payments are sample data only. Nothing is charged.

## View it

Open `index.html` in a browser. On a laptop the app sits in a phone frame with a screen index. On a phone it fills the screen. Use the Screens control in the phone status bar to jump between views.

## Publish on GitHub Pages

1. Create a repository and push this folder.
2. In the repository, open Settings, then Pages.
3. Deploy from the branch that contains `index.html`, folder `/` (root).
4. Share the Pages URL.

Direct links:

- `#parent` Parent Dashboard
- `#find` Find a Nanny
- `#profile` Nanny Profile
- `#booking` Booking & Payment
- `#bookings` My Bookings
- `#nanny` Nanny Dashboard

## Demo path

1. On the welcome screen, choose Parent, then Get Started.
2. Open Elena Vargas. Her card is marked Live demo.
3. Request a booking and confirm it.
4. Open the nanny dashboard and accept the request.
5. Return to My Bookings. The visit is confirmed.

Sign in also offers Maya Chen (parent) and Elena Vargas (nanny). Reset the sample data from the account menu or the screen index.
