POST OAK GROUP — WEBSITE PROTOTYPE
=================================

Files:

- css/styles.css

Preview:
Open index.html in a modern browser. No build tools or server are required.

Images:
The prototype uses remote Unsplash image URLs in CSS. An internet connection is required
for those photography assets. Replace these with client-approved licensed imagery before
production. The supplied Post Oak logo is included locally as a transparent PNG.

Important content notes:
- Existing site figures and selected transaction examples were carried over from the
  content supplied for this prototype. Verify all figures, transaction attribution and
  public-use approvals with Post Oak before launch.
- The six capability areas follow the client's proposed direction. Asset Management,
  Commercial Banking, Investment Research, Private Banking and Wealth Management copy
  is provisional and must be confirmed by the client.
- No new office locations, executive names, licenses or regulatory claims were invented.
- Footer legal wording should be checked against the current approved disclosure.

To publish:
Upload the complete folder contents to a static host (GitHub Pages, Netlify, or the
client's hosting environment). Keep the css, js and assets folders alongside index.html.
