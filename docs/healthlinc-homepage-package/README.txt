# HealthLinc Homepage Concept

A responsive, interactive homepage concept created for presentation purposes.

## Files
- `index.html` — complete page markup, styling, and interactions
- `assets/images/healthlinc-logo.png` — supplied HealthLinc logo
- `assets/images/hero-doctor-patient.jpg` — supplied consultation photo
- `assets/images/nutrition-consultation.jpg` — supplied nutrition consultation photo
- `assets/images/doctor-patient-care.jpg` — supplied doctor and patient photo
- `assets/images/community-outreach.jpg` — supplied community outreach photo

## Preview
Open `index.html` in a modern browser. No build tools or installation are required.

## Notes
- This is a visual concept, not an official HealthLinc website.
- Provider listings, locations, service descriptions, and portal links are illustrative and must be verified before publication.
- The appointment interaction is a front-end demonstration only. It does not book appointments or submit patient information.
- The page does not collect or transmit protected health information.
- The Creative Tugs announcement bar and consultation link are included in the concept.
